Projet PHP

Sujet

Ce projet consiste à concevoir une solution numérique pour gérer les soutenances et les évaluations des étudiants au sein d’un département informatique. L’objectif est de remplacer un fonctionnement manuel basé sur des fichiers PDF par un système centralisé. La solution repose sur la mise en place d’une base de données et d’une application web permettant aux enseignants de saisir directement les notes, de gérer les différentes grilles d’évaluation et d’automatiser les calculs. Elle permet également de sécuriser les données, de limiter les erreurs et de faciliter le suivi des évaluations. Le projet intègre aussi la gestion des statuts des évaluations ainsi que la conservation de l’historique des grilles afin de garantir la cohérence des données dans le temps.
